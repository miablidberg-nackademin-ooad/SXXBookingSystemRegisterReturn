# SXXBookingSystemRegisterReturn – Testimplementation

Detta projekt innehåller en testimplementation för flödet **Registrera återlämning**. Testerna är skrivna med xUnit och NSubstitute och kontrollerar både lyckade flöden och olika situationer där en återlämning inte ska kunna registreras.

## Förutsättningar

- .NET 10 SDK

## Köra testerna

1. Öppna en terminal i projektets rotmapp, där lösningsfilen `SXXBookingSystemRegisterReturn.slnx` finns.
2. Kör följande kommando för att köra testerna:

```bash
dotnet test
```

Testresultatet visas i terminalen efter att testerna har körts.

Alternativt kan testerna köras i test explorer.
